# Prep Stack — do not rebuild what already works

## Core stack

1. **Official GMAT Guide 2026-2027 + official question banks**
   - Ground truth.
   - Use question IDs/references in Atlas, not copied paid text.

2. **Official Practice Exams**
   - Calibration, pacing and score trajectory.
   - These decide whether the system is working.

3. **GMAT Club Forum Quiz + 2026-2027 OG Error Log**
   - Use their bank, timer, difficulty metadata, error log and adaptive quiz instead of rebuilding them.
   - Export/log attempts into 100th Percentile when useful.

4. **GMAT Club Question Patterns**
   - Seed source for the Atlas ontology.
   - Expand and validate the ontology; do not merely copy topic names.

5. **GMAT Ninja free Quant/CR/RC/DI instruction**
   - Intervention library for concepts and process gaps.
   - Particularly useful for foundation repair and word-to-math translation.

6. **Streaks / consistency training**
   - Use after learning a topic.
   - Atlas should track streak reliability separately from raw accuracy and then transition to timed mixed sets.

## Optional paid content

Do not subscribe to multiple full courses simultaneously.

A course earns a place only if the cold diagnostic shows a content gap that free/official resources cannot repair fast enough. e-GMAT already offers personalized planning/diagnosis; TTP offers deep structured content. Buying both and completing both would be negative leverage with a Nov 20 exam.

## Daily loop

1. Learn/fix one blocking primitive.
2. Do a small untimed archetype set until reasoning is clean.
3. Do contrastive "same skeleton / different skin" and "same skin / different skeleton" drills.
4. Build a correctness streak.
5. Move to timed questions.
6. Autopsy every miss into an Error Fingerprint.
7. Let the engine pick the next blocking target.
8. Preserve official questions for calibration, not mindless volume.

## Product differentiation after competitor research

GMAT Club already owns bank/timer/adaptive quiz/error-log infrastructure.
e-GMAT already markets personalized planning, weak-area analytics and "why wrong" diagnosis.
Gurutor explicitly diagnoses which process step failed.

Therefore a generic "AI GMAT tutor that diagnoses mistakes" is **not** enough.

100th Percentile should differentiate through:
- explicit archetype + primitive + trap graph;
- contrastive structural-recognition training;
- portable learner state across external prep sources;
- classifier uncertainty + human-review loop;
- next-best-action optimization across *skills, errors, memory and exam relevance*;
- transparent evidence for every training recommendation.
